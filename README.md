# Credit Card Approval Prediction

## Project Description
This project uses Machine Learning to predict whether a customer's credit card application will be approved or not. The model analyzes customer data like age, income, credit history to make predictions and helps banks automate the approval process.

## Problem Statement
Banks receive thousands of credit card applications daily. Manual verification is slow and error-prone. This ML model provides instant and accurate approval predictions.

## Tech Stack
- **Language**: Python
- **Libraries**: Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
- **Model**: Random Forest Classifier / Logistic Regression
- **Dataset**: Credit Card Application Dataset

## How to Run the Project
1. Install dependencies: `pip install -r requirements.txt`
2. Open `credit_card_approval.ipynb` in Jupyter Notebook
3. Run all cells to train the model and make predictions
